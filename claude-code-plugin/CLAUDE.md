# Claude Code Plugin

Whenever you change the contents of this plugin — skills, commands, or any file under this folder — bump the `version` in `.claude-plugin/plugin.json`.

- Patch bump (`0.1.0` → `0.1.1`) for doc/content edits and fixes.
- Minor bump (`0.1.0` → `0.2.0`) for new skills or commands.
- Major bump (`0.1.0` → `1.0.0`) for breaking changes.
